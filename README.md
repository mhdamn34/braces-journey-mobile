# BracesJourney

A photo-first braces tracker. After every bracket change, capture a
ghost-aligned photo of your teeth, tag the bracket colour, and add a note —
then watch your teeth move month by month in a flipbook player and a
before/after slider. Visits and payments (RM) ride along. Everything stays
on your device.

## Development

    npm install
    npm run ios     # iOS simulator (primary target)
    npm test        # jest unit + component tests
    npm run lint

Architecture notes and the add-a-feature recipe live in `AGENTS.md`.
